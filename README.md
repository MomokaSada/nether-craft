## Nether Craft

![Nether Craftのアイコン](pack_icon.png)

ピグリンとの交易で、土や作物の種、ダイヤモンドなどを入手できるMinecraft統合版向けアドオンです。通常の交易に7種類のアイテムを追加します。

## できること

- 土を入手し、畑や建築に使えます。
- ビートルートの種を入手し、栽培できます。
- ダイヤモンド・ラピスラズリ・銅ブロックを交易で集められます。
- 鶏のスポーンエッグやサドルを入手できます。

## インストール方法

1. [配布ページ](https://github.com/MomokaSada/nether-craft/releases/latest)から、Assetsにある`nether-craft-<version>.mcaddon`をダウンロードします。
2. ダウンロードしたファイルを、Minecraftアプリで開きます。
3. インポートの完了後、利用するワールドの編集画面を開きます。
4. 「ビヘイビアーパック」でNether Craftを選び、有効化します。
5. ワールドを開き、大人のピグリンに金インゴットを渡して交易します。

既存ワールドに導入する場合は、先にワールドをバックアップしてください。取り込むだけでは有効にならないため、遊ぶワールドでの有効化も必要です。

## 交易の仕組み

大人のピグリンへ金インゴットを渡すと、通常どおり交易できます。金インゴット1個につき、既存の19候補と追加の7候補を合わせた全26候補から1種類が選ばれます。

既存アイテムの個数はそのままですが、候補が増えるため出現確率は下がります。例えば、砂利は8〜16個のまま、確率が約8.53%から約7.17%になります。

表の確率は設定値から計算しています。抽選のため、一定回数で目的のアイテムが出る保証はありません。

## 対応環境・注意点

- Minecraft統合版1.21.90以降を対象としています。Java版では使えません。
- 同じピグリン交易を変更する他のアドオンとは競合します。
- バニラの交易内容が将来更新されても、このアドオンには自動反映されません。
